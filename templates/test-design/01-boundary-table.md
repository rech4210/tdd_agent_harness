# 01 경계값 표

| 항목 | 내용 |
|:---|:---|
| 체크리스트 | C-A2, B-3 |
| 함께 쓰는 것 | 02 독립 오라클 성질 (표만으로는 예시 하드코딩을 못 막는다), 03 경계 근처 생성기 |

## 목적

사람이 정한 **경계의 소속**(정확히 경계값은 어느 규칙인가)과 **해상도**(얼마나 작은 차이까지 구별하나)를 표로 그대로 고정한다. 경계 소속은 논리로 유도되지 않는 선택이다. 테스트는 그 선택을 정당화하지 못하고, 기록할 뿐이다.

## 언제 쓰나

- 결과가 입력 구간에 따라 바뀌는 규칙: 임계값, 등급, 기한, 요금 구간, 상태 가드
- 경계 소속과 해상도가 결정 기록(D-xx)에 **선언된 뒤**. 선언이 없으면 표를 쓰지 않고 H2로 돌린다 (C-A3)

## 무엇을 막나

| 실패 | 일반화된 사례 |
|:---|:---|
| 경계 바로 앞의 값을 거친 단위로 반올림 · 절삭해 다른 규칙으로 넘기는 구현 | 표에 "경계 − 큰 단위" 행만 있어서, 입력을 큰 단위로 반올림하는 구현이 모든 행을 통과했다. "경계 − 최소 해상도" 행이 그 구현을 잡는다 |
| 비교 연산자 반전 (`>=` ↔ `>`) | 정확히 경계 행이 없으면 경계 소속이 뒤집혀도 통과한다 |
| 경계에 허용 오차를 둔 구현 | 경계 ± 최소 해상도 행이 없으면 오차가 숨는다 |

## 최소 구조

```
경계 B 마다 (결정 D-xx: 정확히 B 는 <위/아래> 쪽, 해상도 = EPS):
  행 "B+큰여유"   : B + 큰 값       → 위쪽 규칙
  행 "B"          : B               → 결정이 정한 쪽
  행 "B-큰단위"   : B - 큰 단위     → 아래쪽 규칙
  행 "B-EPS"      : B - EPS         → 아래쪽 규칙      ← 반올림 · 절삭 · 허용 오차를 잡는 행
  (필요하면) "B+EPS"
정의역 끝 행: 최소값, 최대값(있으면), 0, 음수(허용되면)

각 행 검사: 출력 전체 (값 + 규칙 ID + 파생 값). 값 하나만 보지 않는다
행 ID: 사람이 읽는 이름 ("B", "B-EPS") — 실패 메시지가 곧 명세 위반 설명이 된다
```

## 게으른 구현 예

| 게으른 구현 | 이 표가 잡는 방법 |
|:---|:---|
| 입력을 큰 단위로 반올림한 뒤 비교 | "B-EPS" 행이 반올림 후 B가 되어 위쪽 규칙으로 넘어간다 → 실패 |
| `>` 대신 `>=` | "B" 행 → 실패 |
| 경계에 작은 허용 오차 | "B-EPS" 행 → 실패 |
| 표의 행 입력만 정확히 처리 (조회표) | **표는 못 잡는다.** 02 독립 오라클 성질이 잡는다 |

## 흔한 실수

| 실수 | 결과 |
|:---|:---|
| 경계 한쪽 행만 있음 | 반대쪽 오류가 숨는다 |
| 해상도를 결정하지 않고 "B-1" 행을 씀 | "1"이 어떤 단위인지 모호. 해상도가 더 작은 타입에서 반올림 구현이 통과 |
| 규칙 ID 없이 값만 검사 | 값이 우연히 같은 다른 규칙이 통과 |
| 표만 있고 성질 테스트 없음 | 행 입력만 하드코딩한 구현이 통과 |
| 표의 기대값을 구현 상수에서 import | 상수가 틀리면 표도 같이 틀린다. 기대값은 결정에서 옮겨 적는다 |

## Python 참조 구현

```python
"""<대상> 경계값 표. 지키는 결정: D-xx (경계 소속), D-yy (해상도: 반올림 없음)."""
from datetime import timedelta

import pytest

from mypkg.tiers import tier_for  # 예시: 프로젝트의 대상으로 바꾼다

H = timedelta(hours=1)
SEC = timedelta(seconds=1)
EPS = timedelta(microseconds=1)  # 이 타입의 최소 해상도 (D-yy)
B = 24 * H  # 예시 경계 (D-xx: 정확히 B 는 위쪽 규칙)


@pytest.mark.parametrize(
    "elapsed, rule_id",
    [
        (3 * B, "UPPER"),
        (B, "UPPER"),  # 정확히 경계
        (B - SEC, "LOWER"),  # 큰 단위로 모자람
        (B - EPS, "LOWER"),  # 최소 해상도로 모자람: 반올림 · 절삭 구현을 잡는다
        (timedelta(0), "LOWER"),
    ],
    ids=["3B", "B", "B-1s", "B-eps", "zero"],
)
def test_boundary_table(elapsed, rule_id):
    result = tier_for(elapsed)
    assert result.rule_id == rule_id
```
