# 09 공허한 참 방지

| 항목 | 내용 |
|:---|:---|
| 체크리스트 | B-1, B-7, B-9 |
| 함께 쓰는 것 | 02 (완전성 = 오라클과 같음), 10 (회귀 장치 자체의 공허한 참) |

## 목적

"위반 없음", "모두 만족", "노출 없음" 형태의 검사가 **검사 대상 0개**로 참이 되지 않게 한다. "실패하지 않음"과 "확인함"은 다르다.

## 언제 쓰나

- 파일 · 모듈 · 레코드 목록을 모아서 "위반 목록 == 비어 있음"을 검사할 때 (구조 규칙, 금지 패턴)
- "일어나면 안 되는 일"을 검사할 때 (민감정보가 로그에 없음, 금지 호출 없음)
- 목록을 돌려주는 계산의 안전성 성질("나온 것은 모두 유효")
- 모든 것에 대한 성질(`for all`), 회귀 장치 · 검증 스크립트

## 무엇을 막나

| 실패 | 일반화된 사례 |
|:---|:---|
| 대상 0개에서 통과 | 구조 규칙 테스트를 처음 썼을 때, 소스가 하나도 없는데 일부 검사가 통과했다. "금지 import를 하는 파일이 없다"가 파일 0개라서 참이었다 |
| 아무것도 하지 않는 구현 | "로그에 민감정보 없음"은 로그를 남기지 않으면 참이다 |
| 빈 목록 구현 | 안전성 성질만 있으면 빈 목록을 돌려주는 구현이 통과한다 |
| 검증 장치의 공허한 참 | 게으른 후보 검증 스크립트가 실제 구현을 import해서, 모든 후보가 "통과"로 보였다 (10) |

## 최소 구조

```
대상 = 수집()
단언 len(대상) > 0, "검사할 것이 없다: <위치>"      # 위반 검사보다 먼저
단언 위반(대상) == []

부정 검사 ("X 가 없다")에는 양성 대조를 붙인다:
  단언 기대하는 흔적이 있다 (로그가 남았다, 마스킹된 형태가 있다)
  단언 금지된 형태는 없다

목록 결과: 안전성 + 완전성 (구현 결과 == 오라클 결과, 02)
for-all 성질: 실제로 실행된 예시 수 확인 (대부분 걸러지면 공허해진다)
환경 의존: 대상 자원이 없으면 skip 이 아니라 실패
```

## 게으른 구현 예

| 게으른 구현 | 이 방지가 잡는 방법 |
|:---|:---|
| 소스를 비우거나 다른 위치로 옮김 | 대상 0개 → 실패 |
| 로그 · 출력을 남기지 않음 | 양성 대조 실패 |
| 빈 목록 반환 | 완전성 (오라클과 비교) |
| 테스트 실행기를 무력화 | 실행된 테스트 수 · 예시 수 확인, 테스트 도구 import 금지(구조 규칙) |

## 흔한 실수

| 실수 | 결과 |
|:---|:---|
| `all([])`이 참이라는 것을 잊음 | 빈 목록에 대한 `all`은 항상 통과 |
| 루프 안에만 단언이 있음 | 루프가 0회 돌면 아무것도 검사하지 않는다 |
| 생성기에서 대부분을 걸러 냄 | 실효 예시 수가 0에 가까워진다. 걸러 내지 말고 만들 때 맞춘다 |
| 대상 경로가 없을 때 skip | Red 상태가 초록으로 보인다. 대상이 없으면 실패 |
| 부정 검사만 있고 양성 대조가 없음 | 아무것도 하지 않는 구현이 통과 |

## Python 참조 구현

```python
"""구조 규칙 · 부정 검사의 공허한 참 방지. 지키는 결정: D-xx (레이어 규칙), INV-yy (민감정보 비노출)."""
import logging
from pathlib import Path

from mypkg.usecases import register  # 예시

SRC = Path(__file__).resolve().parents[2] / "src" / "mypkg"  # 예시 경로


def source_files(rel: str) -> list[Path]:
    """검사 대상. 0개면 실패한다: 검사할 것이 없으면 '위반 없음'은 공허한 참이다."""
    target = SRC / rel
    files = [target] if target.is_file() else sorted(target.rglob("*.py"))
    assert files, f"검사할 파일이 없다: {target}"
    return files


def test_core_does_not_import_adapters():
    bad = [f for f in source_files("core") if "mypkg.adapters" in f.read_text(encoding="utf-8")]
    assert bad == []


def test_secret_is_masked_in_logs(caplog):
    caplog.set_level(logging.INFO)
    register(secret="S-1234-5678")
    assert caplog.records, "로그가 하나도 없다: '노출 없음'이 공허하게 참이 된다"
    assert "S-1234-5678" not in caplog.text
    assert "S-****-5678" in caplog.text  # 양성 대조: 마스킹된 형태가 실제로 있다
```
