# 공통 기본값 (DEF-##) — {{PROJECT}}

> **머리말**: 이 문서는 프로젝트 전역에서 반복되는 기본 동작 규칙을 정의한다. 슬라이스 명세는 매번 사람에게 질문하는 대신 승인된 `DEF-##` 를 인용한다.
>
> **일괄 승인**: 프로젝트 시작 때 사람이 아래 후보를 한 번에 검토해 **하나의 결정 기록 `D-##`** 로 승인 · 거부한다(필요하면 후보를 고치거나 더한다). 승인한 행의 **승인 칸**에 그 `D-##` 를 적는다. 승인 칸이 정의된 `D-##` 가 아닌 DEF(`[승인 대기]` 등)는 경계 표에서 **인용할 수 없다**(GT `boundaries`). 인용하지 않는 후보는 그대로 두어도 된다.
>
> 규칙을 바꾸려면 기존 번호를 수정하지 않고 새 번호(`DEF-##`)로 대체한다 (append-only).
>
> **공통 기본값과 모델 기본값의 구분**:
> - **공통 기본값 (`DEF-##`)**: 사람이 승인하여 프로젝트 전역에 적용되는 규칙. 이 문서에만 정의한다.
> - **모델 기본값**: 특정 슬라이스에서 에이전트가 고른 값. 명세에 **DEF 로 번호** 매기지 않고 결정 기록 `D-##` 에 출처(`<에이전트>`)와 함께 남기며, S3 적합도 카드에서 사람이 일괄 확인한다(명세 안 DEF 정의는 GT `defaults_scope` 위반). 둘 이상의 슬라이스에서 반복되면 공통 기본값 후보로 올린다.
