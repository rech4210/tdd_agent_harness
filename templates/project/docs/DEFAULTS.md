# 공통 기본값 (DEF-##) — {{PROJECT}}

> **머리말**: 이 문서는 프로젝트 전역에서 반복되는 기본 동작 규칙을 정의한다.
> 사람이 프로젝트 시작 시 한 번 승인하며, 슬라이스 명세는 매번 사람에게 질문하는 대신 `DEF-##` 를 인용한다.
> 규칙을 바꾸려면 기존 번호를 수정하지 않고 새 번호(`DEF-##`)로 대체한다 (append-only).
>
> **공통 기본값과 모델 기본값의 구분**:
> - **공통 기본값 (`DEF-##`)**: 사람이 승인하여 프로젝트 전역에 적용되는 규칙.
> - **모델 기본값**: 특정 슬라이스에서 에이전트가 고른 값. 결정 기록에 출처(`<에이전트>`)를 명시하고 S3 적합도 카드에서 사람이 일괄 확인한다. 둘 이상의 슬라이스에서 반복되면 공통 기본값(`DEF-##`) 후보로 올린다.
