# tdd-agent-harness

제약으로 에이전트 작업을 신뢰할 수 있게: 잠긴 테스트 · 세션 밖 게이트 판정 · 역할 분리.

## 저장소 구조

- `harness/`: 언어 독립적인 핵심 하네스 도구 및 판정 엔진
- `adapters/`: 언어별 테스트 러너 및 정적 분석 도구 연동 어댑터
- `config/`: 품질 게이트 및 역할 배정 규칙 설정
- `templates/`: 사양 주도 개발(SDD), 테스트 설계 및 역할 가이드 틀
- `docs/`: 슬라이스 생명주기 및 격리 위임 절차 문서

## 빠른 시작

새 프로젝트 생성:
```sh
python harness/new_project.py <폴더> --package <이름>
```

품질 게이트 실행:
```sh
python harness/run_gates.py --role implementer --base <기준 커밋>
```

## 품질 게이트 목록

`config/gates.toml` 기준 게이트 목록:

- **GA**: 역할 배정 제약
- **G0**: 보호 경로 · 우회 패턴 · 테스트 잠금
- **GT**: 요구 추적성 (SDD)
- **GC**: 헌법 = 설정
- **G1**: 아키텍처 적합성
- **G2**: 단위 · 성질 · 유스케이스 · 계약(Fake)
- **G3**: 레이어별 분기 · 함수 커버리지
- G4 (인수 테스트) · G5 (실제 자원 통합): 설정 틀에 예시로만 있고 기본으로 꺼져 있다
- **G6**: 돌연변이 점수
- **G7**: 정적 품질: 복잡도 · 타입 · 보안 스캔

## 상태

**실험 단계**

- **검증 범위**: Python 어댑터, 두 실험 프로젝트에서 사용, `harness/selftest/` 의 자기 검사 19개 통과.
- **한계**: 위험도 프로필 및 검토 예산은 문서 규칙에 기반하며, 현재 단일 언어(Python) 어댑터만 제공됩니다.
