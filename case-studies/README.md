# 사례 연구

하네스를 실제 작업에 쓰며 확인한 것을 기록한다.

## 작성 규칙

- 사람이 직접 쓴 글을 기본으로 한다.
- AI 가 초안을 쓴 글은 맨 위에 **“AI 초안 · 사람 검토”** 상태를 표시한다. 사람이 검토를 마치기 전에는 “검토 전”으로 둔다.
- 수치는 기록(판정 문서 · 실행 기록)에서 가져온 값만 쓰고, 해석은 사실과 구분해 적는다.
- 사람 검토는 사실 확인과 해석의 타당성을 본다. 문장 다듬기만으로 검토를 마쳤다고 표시하지 않는다.
